
Stock Price Prediction Project using IBM SPSS Modeler

Objective

The objective of this project is to analyze and predict stock price trends using IBM SPSS Modeler and machine learning techniques.

Dataset Description

The dataset contains:
- Open Price
- High Price
- Low Price
- Close Price
- Volume

 Tools Used

- IBM SPSS Modeler
- Machine Learning
- Data Visualization
- GitHub


 Workflow

1. Import Dataset
2. Data Preprocessing
3. Feature Engineering
4. Model Building
5. Prediction Analysis

 Models Used

- C&R Tree
- Regression


Result

The C&R Tree model achieved the highest prediction accuracy.


Conclusion

The project successfully predicts stock prices using IBM SPSS Modeler.
